# Blog Post Page

A semantic blog post page built using HTML only, as part of the [roadmap.sh HTML Projects](https://roadmap.sh/projects/blog-post-page).

## Technologies

- HTML5

## Project Requirements

- Semantic HTML structure
- Proper heading hierarchy (h1, h2, and h3)
- Semantic text elements (paragraphs, lists, blockquotes, and code)
- Meaningful emphasis using `em` and `strong`
- Descriptive links
- Figure with image, alt text, and figcaption
- SEO Meta Description
